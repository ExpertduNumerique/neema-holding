# Prompt 09 — Page pôle « Neema Store »

Prérequis : prompt 04 exécuté (suis la même approche d'architecture).
Lis `AGENTS.md` §2.

## Objectif

Ajouter le contenu du pôle Store : `app/poles/store/page.tsx` ou entrée
`lib/poles.ts`.

## Contenu du pôle

- **Nom** : Neema Store
- **Logo** : `public/images/neema/logo_store.png`
- **Description officielle** : distribution de produits et services de
  qualité destinés aux professionnels comme aux particuliers.
- **Contenu additionnel repéré sur le kakémono** (transcription visuelle à
  reformuler proprement) : « Neema Mall » regroupant tous les produits du
  groupe, format supermarché, vente de produits agroalimentaires.
- **Pictogramme du logo** : caddie de courses.

## Structure de la page

Même structure que les autres pôles : hero, section « Ce que nous
faisons » (distribution + concept « Neema Mall »), fil d'Ariane, CTA
contact, liens vers les autres pôles.

Ce pôle est le candidat le plus évident pour devenir un vrai e-commerce
plus tard (comme le marketplace de recaptech). **Ne construis pas de
catalogue produits/panier maintenant** — reste sur une page vitrine
présentant le concept, sauf si un prompt ultérieur dédié te le demande
explicitement.

## Metadata

Titre de page « Neema Store » (+ suffixe du template), description reprenant
la description officielle du pôle.

## Contraintes

Identiques aux prompts précédents.

- Vérifie le lien depuis le mega-menu et la page d'accueil.
- À ce stade, les 6 pages de pôles existent : relis rapidement les 6 pour
  vérifier la cohérence de ton (même style de titre, même longueur de
